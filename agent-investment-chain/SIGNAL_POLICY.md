# 信号策略和提醒规则

系统只能输出条件化提醒。所有提醒必须服务于风险预算，而不是预测确定涨跌。

## 信号类型

| 信号 | 含义 | 允许动作 |
|---|---|---|
| `no_trade` | 条件不足或风险过高 | 不交易，只记录原因 |
| `watch` | 进入观察池 | 设置触发价和复盘任务 |
| `pilot_build` | 试探建仓 | 小仓位验证，通常不超过单票上限的 25%-33% |
| `add` | 加仓 | 只在盈利持仓或风险下降时触发 |
| `hold` | 持有 | 维持仓位，更新止损/止盈 |
| `take_profit_partial` | 分批止盈 | 降低仓位，保留尾仓 |
| `take_profit_full` | 全部止盈 | 退出并记录原因 |
| `stop_loss` | 止损 | 执行风险纪律 |
| `exit_risk` | 风险退出 | 基本面/事件/流动性恶化导致退出 |

## 禁入条件

任一条件触发时，最高只能输出 `watch` 或 `no_trade`：

- ST、退市风险、重大财务造假嫌疑。
- 停牌、连续一字涨停/跌停、无法合理成交。
- 日均成交额低于用户流动性要求。
- 关键财务数据缺失或冲突无法解释。
- 公告显示重大诉讼、监管问询、债务违约、控股股东高比例质押且无解释。
- 回测显示策略在相似环境中长期负收益或最大回撤超过用户限制。

## 评分框架

每项 0-5 分：

- `fundamental_score`：基本面质量。
- `valuation_score`：估值合理性。
- `theme_score`：热点/产业链有效性。
- `technical_score`：技术执行位置。
- `flow_score`：资金行为。
- `risk_score`：风险可控性，分数越高风险越可控。
- `backtest_score`：历史验证质量。

建议阈值：

- `watch`：总分 >= 20，且无禁入条件。
- `pilot_build`：总分 >= 26，技术触发成立，风险分 >= 3，回测分 >= 3。
- `add`：总分 >= 30，原仓盈利或风险下降，价格确认突破/回踩有效。
- `take_profit_partial`：达到第一目标位、RSI/量价出现衰竭、或估值进入高分位。
- `stop_loss`：跌破失效价、基本面证伪、或组合风险超限。

阈值可按用户风险偏好调整，保守型提高阈值并降低仓位。

## 建仓规则

试探建仓必须同时满足：

- 基本面不差：`fundamental_score >= 3`。
- 风险可控：`risk_score >= 3`。
- 技术位置明确：有触发价、止损价和支撑来源。
- 回测不是负期望：`backtest_score >= 3`。
- 单票最大亏损不超过账户总资金的预设比例。

试探仓位公式：

`shares = floor((account_equity * risk_per_trade) / (entry_price - stop_price) / 100) * 100`

同时受单票最大仓位、流动性和板块暴露限制。

## 加仓规则

加仓只能发生在：

- 首仓盈利且价格未远离合理买点。
- 新增证据强化原逻辑。
- 突破后回踩不破，或平台放量突破后 1-3 日确认。
- 加仓后总风险仍不超过账户预算。

禁止摊低式加仓，除非原计划明确支持分批低吸且基本面没有恶化。

## 止损规则

止损触发优先级：

1. 基本面证伪：业绩、现金流、监管、重大事件使原逻辑失效。
2. 技术失效：收盘跌破关键支撑，或跌破 ATR/均线止损。
3. 时间止损：达到观察周期仍未按预期运行。
4. 组合止损：行业或组合风险超限。

止损必须写明：触发价、执行条件、是否等待收盘确认。

## 止盈规则

止盈不只看收益率，还看预期兑现程度：

- 第一目标位：前高、箱体上沿、估值中性区、1.5R-2R。
- 第二目标位：估值乐观区、主题高潮、量价衰竭、3R 以上。
- 移动止盈：跌破 10/20 日均线、ATR trailing stop、放量长上影。

分批止盈优先于一次性全出，除非基本面或事件风险突然恶化。

## 提醒输出格式

每条提醒必须包含：

- `signal`
- `confidence`
- `trigger_condition`
- `entry_zone`
- `stop_condition`
- `take_profit_plan`
- `position_limit`
- `evidence`
- `bear_case`
- `next_review_time`

参考结构见 [schemas/signal.schema.json](schemas/signal.schema.json)。
