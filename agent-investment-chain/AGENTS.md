# 分析 Agent 分工

这些角色可以由一个智能体顺序执行，也可以由多个智能体并行执行。最终由 `Signal Orchestrator` 汇总。

## 1. Data Steward

职责：

- 拉取并校验行情、财报、公告、行业、热点、资金和指数数据。
- 标记数据来源、时间戳、复权方式、缺失字段。
- 发现数据冲突时优先保留一手来源，并列出差异。

输出：

- 数据完整性报告。
- `insufficient_data` 字段。
- 证据清单。

## 2. Fundamental Analyst

职责：

- 分析收入、利润、现金流、ROE、资产负债、毛利率、应收、存货、商誉。
- 判断公司是否具备进入观察池的基本质量。
- 区分周期性增长、一次性收益和真实经营改善。

输出：

- `fundamental_score`。
- 核心驱动和核心疑点。

## 3. Valuation Analyst

职责：

- 做历史估值分位、同业估值和情景估值。
- 判断市场价格是否已经充分反映乐观预期。
- 给出估值上限、合理区间和估值压缩风险。

输出：

- `valuation_score`。
- 悲观/中性/乐观估值区间。

## 4. Theme And Industry Analyst

职责：

- 拆热点、政策、产业链和公司业务敞口。
- 验证热点是否能传导到收入、利润或估值。
- 判断热点阶段：启动、扩散、高潮、退潮。

输出：

- `theme_score`。
- 受益链条和证据强度。

## 5. Technical Analyst

职责：

- 判断趋势、动量、均线、成交量、波动率、相对强弱。
- 识别突破、回踩、背离、衰竭、假突破。
- 给出可执行价格区域，而不是只给方向。

输出：

- `technical_score`。
- 入场触发、失败触发、止损参考。

## 6. Support Resistance Analyst

职责：

- 识别支撑、阻力、成交密集区、缺口、箱体和均线位。
- 给出关键价位的来源和有效性。
- 区分“可观察价位”和“可执行价位”。

输出：

- 支撑/阻力表。
- 突破、回踩、跌破动作建议。

## 7. Capital Flow Analyst

职责：

- 分析成交额、换手率、龙虎榜、融资融券、机构席位、ETF/行业资金。
- 判断资金是持续流入、短线脉冲、出货还是流动性陷阱。

输出：

- `flow_score`。
- 资金行为解释。

## 8. Bear Case Analyst

职责：

- 写最强反方报告。
- 找出看多逻辑中最脆弱的假设。
- 给出必须退出、降级或暂停跟踪的证据。

输出：

- `bear_case_strength`。
- 风险清单和失效条件。

## 9. Backtest Researcher

职责：

- 把研究观点转成可回测规则。
- 在个股、行业样本和市场环境中验证。
- 标记过拟合、样本不足和不可交易问题。

输出：

- 回测摘要。
- 是否允许升级到候选交易提醒。

## 10. Signal Orchestrator

职责：

- 汇总所有角色输出。
- 应用禁入规则、评分阈值和仓位约束。
- 生成条件化提醒。

输出：

- 最终信号 JSON。
- Markdown 报告。
- 下次复盘任务。
