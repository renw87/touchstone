# Seat Classification

Classify conservatively:

- Institution: official institution-only seat label.
- Quant: known high-frequency or quantitative trading seat, if verifiable.
- Hot money: known active branch, only when supported by reliable references.
- Branch/unknown: default class when evidence is weak.

Do not invent seat identity. If evidence is unavailable, mark `unknown`.

High-risk clues:

- huge net sell after theme climax.
- repeated one-day round trips.
- high turnover with price failing to advance.
- unknown seats dominating after continuous limit-up moves.
