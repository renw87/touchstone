# Panel Rubric

Each seat scores 0-5:

- 0: directly contradicts thesis.
- 1: weak and unverified.
- 2: incomplete.
- 3: acceptable but not decisive.
- 4: strong with evidence.
- 5: strong, timely, and supported by multiple sources.

The bear case must be written before the final signal.

If the bear case finds a thesis-invalidating issue, cap signal at `watch` or `no_trade`.
