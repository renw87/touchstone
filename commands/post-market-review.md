# Post-market Review

Use the Harness task `harness/tasks/post_market_review.yaml`.

Update:

- close, amount, turnover.
- support/resistance changes.
- capital flow and LHB if available.
- trigger result.
- signal changes and next review.

Every review must answer:

- what evidence changed?
- did the thesis change?
- did a trigger fire or fail?
- is risk still inside budget?
